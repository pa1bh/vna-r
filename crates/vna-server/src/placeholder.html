vna-server

This server runs, but it was built without the web client, so there is no page to show here.

To build it in: run scripts/build-web.sh in the vna-r source tree, then build vna-server again. Or start the server with --web <dir>, pointing at a folder with index.html, vna-gui.js and vna-gui_bg.wasm.

The vna-r program on a computer can connect to this server without the page.
